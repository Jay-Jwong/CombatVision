# CombatVision

AI-powered Boxing & MMA Technique Analysis System

## Overview

CombatVision is a computer vision project designed to analyze boxing and mixed martial arts (MMA) techniques from video footage.

The project aims to:

* Detect human body keypoints using pose estimation
* Analyze striking mechanics
* Measure hip and shoulder rotation
* Classify punching techniques
* Generate automated training reports
